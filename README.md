### Описание
Проект представляет собой тематический сайт, посвященный системам управления контентом. Сайт состоит из 8+ связанных страниц. 
Верстка выполнена семантически (HTML5), является адаптивной (Mobile-First с тремя брейкпоинтами) и кроссбраузерной.
Для оформления использован микро-фреймворк Pylon в связке с кастомными CSS-стилями (flexbox, переменные, медиа-запросы).

### Инструкция по запуску локально
1. Склонируйте репозиторий: `git clone https://github.com/твой-логин/cms-project.git`
2. Откройте файл `index.html` в любом современном браузере.
